# Agenda de Compromissos

Uma aplicação web desenvolvida para auxiliar no gerenciamento de compromissos e tarefas do dia a dia, permitindo cadastrar, editar, excluir, pesquisar e concluir atividades de forma simples e intuitiva.

## Funcionalidades

* Cadastro de compromissos
* Edição de compromissos
* Exclusão de compromissos
* Pesquisa em tempo real
* Marcação de compromissos concluídos
* Dashboard com estatísticas
* Integração com API REST
* Layout responsivo para desktop e dispositivos móveis

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* MockAPI
* GitHub
* Vercel

## Integração com API

O projeto utiliza uma API REST hospedada no MockAPI para armazenar os compromissos online.

Operações implementadas:

* GET → Buscar compromissos
* POST → Cadastrar compromissos
* PUT → Atualizar compromissos
* DELETE → Remover compromissos

## Interface

A interface foi desenvolvida utilizando conceitos modernos de design, incluindo:

* Efeito Glassmorphism
* Gradientes modernos
* Fonte Orbitron para destaque visual
* Componentes responsivos
* Feedback visual para ações do usuário
